开始使用
  1. 点左下「启动并进入云桌面」进入远程 Ubuntu 桌面，文件都在 /workspace，手机浏览器也能用。
  2. 「本机伴侣」= 你自己电脑上运行的托盘应用，负责文件同步和本地命令执行。它显示「离线」只是同步暂停，云桌面本身不受影响，设备列表里的 chaojin-home-server 就是家里绑定的那台。
  3. 新电脑要用：安装托盘应用 → 点「生成配对码」→ 把口令粘贴进托盘，即完成绑定。
